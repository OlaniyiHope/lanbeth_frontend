# LambethCare Professional React UI

This version keeps the existing LambethCare page flow and adds functionality without removing the existing routes.

## Added
- Professional green/white responsive UI.
- Landing page with video background and image fallback.
- Login and sign-up pages.
- Existing-email account validation using localStorage.
- Demo account: `admin@lanbethcare.com` / `Admin@123`.
- Client View Details modal.
- Client Edit modal.
- Client Delete confirmation and persistent deletion.
- Staff View Details modal.
- Staff Edit modal.
- Staff Delete confirmation and persistent deletion.
- Report View, Edit and Delete actions.
- Staff induction View, Edit and Delete actions.
- Persistent portal records through localStorage.
- Responsive sidebar, cards, tables, forms and modals.
- Page transitions, hover states and entrance animations.
- Existing dashboard/client/staff/document/report/policy/audit/induction routes retained.

## Run

```bash
npm install
npm run dev
```

The project uses Vite, React, React Router and Lucide React icons.
